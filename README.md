# NetScope

Русскоязычное desktop-приложение для обнаружения устройств в локальной сети на Tauri v2, React, TypeScript и Rust.

## Что реализовано

- Реальный асинхронный TCP-сканер подсети CIDR с ограничением параллельных проверок и остановкой.
- Получение локальных интерфейсов, ARP/MAC, reverse DNS и базовая классификация устройств по hostname/портам.
- SQLite-хранилище устройств, событий, координат карты и заметок.
- Dashboard без seed/mock устройств: до первого запуска сканирования список пуст.
- Интерактивная карта React Flow с перемещением узлов и сохранением координат.
- Таблица устройств, поиск, фильтр по типу, карточка деталей, редактирование имени и комментария.
- Журнал событий и русская тёмная UI-система.

## Запуск

```powershell
npm install
npm run tauri dev
```

Для production-сборки Windows:

```powershell
npx tauri build
```

Результаты сборки находятся в `src-tauri/target/release/bundle/`.

Сканирование выполняется только через Tauri-приложение. Запуск `npm run dev` показывает интерфейс, но намеренно не подставляет фиктивные данные и сообщает о необходимости Tauri для сетевых команд.

## Ограничения текущего вертикального среза

SNMP/LLDP/CDP, WMI/WinRM/SSH-мониторы, планировщик, уведомления Telegram/Discord/email и расширенные форматы экспорта подготовлены как следующие модули, но не включены в этот первый рабочий срез. Для обнаружения устройств сейчас используются TCP-порты, ARP и reverse DNS — без внешних API и моковых значений.
